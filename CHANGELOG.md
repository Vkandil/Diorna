# Release notes

## 0.1.0 — Initial open-source release

- Local-first Markdown notes with block editing, links, graph, revisions, templates, flashcards, and references.
- Free-form Canvas maps with authoring, presentation, nesting, and image export.
- Calendar, task, recurrence, reminders, natural-language entry, and drag scheduling.
- Habit and metric grids with statistics, heatmaps, charts, and spreadsheet export.
- Monthly, yearly, custom, and combined private recaps with optional local or remote prose.
- Isolated workspaces, customizable dashboards, split panes, command palette, quick capture, tray integration, import, backup, and portable export.

See the repository history for implementation-level changes.
