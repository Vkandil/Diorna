# Release notes

## 0.1.0 — Initial open-source release

- Local-first Markdown notes with block editing, links, graph, revisions, templates, flashcards, and references.
- Free-form Canvas maps with authoring, presentation, nesting, and image export.
- Calendar, task, recurrence, reminders, natural-language entry, and drag scheduling.
- Habit and metric grids with statistics, heatmaps, charts, and spreadsheet export.
- Monthly, yearly, custom, and combined private recaps with optional local or remote prose.
- Isolated workspaces, customizable dashboards, split panes, command palette, quick capture, tray integration, import, backup, and portable export.
- Diorna AI creation plans for notes, connected Maps, calendar items, and habits,
  with explicit previews, cancellation, one bounded repair attempt, provider
  usage/cost reporting, configurable limits, generated-note folders/tags, and
  reversible restructuring of an existing Map.
- Large nested Obsidian and mixed Notion imports are covered by realistic
  import/undo tests.
- The warm Diorna palette is now the default theme while neutral light, dark,
  system, and custom accent choices remain available; official brand assets
  replace the placeholder mark across the interface and Windows packages.
- Notes and Maps now share rich, offline-cached link previews with thumbnails,
  site metadata, smart paste/drop, open/copy/refresh controls, portable export,
  and private-network fetch protection.

See the repository history for implementation-level changes.
