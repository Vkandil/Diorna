# Focus

Focus is Diorna's execution layer. It does not duplicate tasks, projects, notes,
maps, habits, goals, or training data. A priority or session can point to any of
those sources while keeping only execution-specific evidence: planned and actual
time, pauses, distractions, and the end-of-session review.

Timers persist a timestamp plus accumulated seconds so a running session remains
accurate after navigation, refresh, sleep, or an application restart.

Completed sessions feed Home and Recap. Diorna AI can plan focus blocks against
exact workspace resources, but starting a timer remains an explicit user action.
