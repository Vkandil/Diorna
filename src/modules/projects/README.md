# Projects & Goals

Projects coordinate existing Diorna entities instead of duplicating them. Calendar remains the
source of truth for tasks, calls and deadlines; Notes and Maps hold knowledge; Daily and Training
hold repeated behaviour; Metrics hold measurable outcomes.

- A Goal describes a longer-term result, purpose and success definition.
- A Project is a finite commitment with an outcome, status, health, milestones and next action.
- Project progress can be automatic from linked tasks and milestones, manually controlled, or
  driven by a Daily metric.
- Updates form a lightweight decision and review log.
- Every entity remains isolated by workspace.
